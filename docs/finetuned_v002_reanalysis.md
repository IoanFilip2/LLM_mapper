## Matched analysis design

Use the same selected CDS FASTA and metadata, mean pooling, 3,998-base contexts,
length-weighted whole-CDS pooling, float32 SDPA, and normalized cosine retrieval
as the base model. Reference embedding uses MPS batch size two. The same 12 target
symbols and palette are reused. A new reference-only UMAP is fit with seed 42,
30 neighbors and minimum distance 0.25; query reads use only its saved transform.
Base and fine-tuned UMAP coordinates are separate spaces, not aligned axes.

Louvain uses the original-space cosine kNN graph, k=30 and resolution 0.3.
Cluster IDs are assigned anew and should not be equated to base-model cluster
IDs. All resulting clusters are characterized using existing HGNC-family,
MANE-selection and length analyses; these exploratory tests are distinct from
the omitted SW analysis.

Read selection is copied and checksum-checked, not repeated. All 935 reads are
embedded with the exact reference encoder configuration. Reports are labeled
**Fine-tuned v002**, not zero-shot. The 12 evaluation genes were excluded from
fine-tuning anchors, negative donors and validation. Metrics include top-1,
top-5, top-50, top-100 and top-250 accuracy, per-gene sensitivity/specificity,
precision/F1, confusion matrices and reference-UMAP read overlays. Top-k for
k≥12 is trivially 100% in the 12-target universe. Independent sequence and
full-CDS self-retrieval controls and the Q30 sensitivity subset are rerun.
